# EDS223 HW3: Prioritizing Sustainable Protein Sources with Marine Aquaculture

## Description

This repository contains files related to the HW3 assignment "Prioritizing potential aquaculture" for EDS223, part of the UCSB MEDS 2027 graduate program. In this assignment, we visually and numerically determined which US West Coast Exclusive Economic Zones (EEZs) encompassed the most suitable area for potentially expanding marine aquaculture for oysters and Iceland scallops. In addition to this analysis, one of the main goals of this assignment was to practice vector and raster geospatial operations in R.
